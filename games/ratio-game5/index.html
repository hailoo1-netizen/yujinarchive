카드를 뒤집어 기억해

게임 방법

  1. 내 차례가 되면 카드 2장을 뒤집어요. 먼저 뒤집은 수가 앞, 나중에 뒤집은 수가 뒤에 와서 비가 돼요.
  2. 카드 2장을 더 뒤집은 뒤, 이 두 수로 비례식을 세울 수 있는지 맞혀요. 두 수의 순서는 바꿔도 돼요.
  3. “비례식이 돼요”를 맞히면 카드 4장을 가져가요(+4점). “안 돼요”를 맞히면 +1점이에요.
  4. 차례가 끝나면 남은 카드는 다시 엎어져요. 어디에 어떤 수가 있었는지 잘 기억해 두세요!
  5. 남은 카드로 더 이상 비례식을 만들 수 없으면 게임이 끝나요.
