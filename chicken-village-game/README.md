# 사회 치킨 마을 창업 (학급별 연동)

치킨 원가표를 보고 모둠별로 메뉴를 설계한 뒤, 판매 라운드에서 서로의 치킨을 사고파는 사회 수업용 웹앱입니다.
구글 스프레드시트와 연결된 Apps Script 웹앱이라서, 깃허브에서는 코드만 보관하고 실제 게임은 구글에서 실행됩니다.

## 바로 하기

- 게임 열기: (배포한 웹앱 주소를 여기에 붙여 넣으세요 — https://script.google.com/macros/s/.../exec)

## 파일

| 파일 | 역할 |
| --- | --- |
| `Code.gs` | 서버 코드: 원가 계산, 메뉴 저장, 구매, 교사용 기능 |
| `Index.html` | 학생·교사 화면 |

## 내 구글 계정에 새로 설치하기

1. 구글 스프레드시트를 새로 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `Code.gs` 내용을 그대로 붙여 넣습니다.
3. **파일 추가(+) → HTML**로 파일을 만들고 이름을 정확히 `Index`로 지은 뒤 `Index.html` 내용을 붙여 넣습니다.
4. 함수 목록에서 `setup`을 골라 한 번 실행하면 [설정]·[메뉴]·[학생]·[주문] 시트가 만들어집니다.
5. [설정] 시트에서 학급 목록, 모둠 수, 시작 자금, **교사 비밀번호**(기본값 1234)를 바꿉니다.
6. **배포 → 새 배포 → 웹 앱**, 실행 계정은 '나', 액세스 권한은 '모든 사용자'로 배포하고 나온 주소를 학생들에게 줍니다.

## 수업 흐름

교사용 화면에서 학급별로 단계를 바꿉니다.

1. **설계**: 모둠별로 옵션을 골라 메뉴를 만들고 이윤과 판매 가격을 정합니다.
2. **판매**: 학생마다 시작 자금으로 다른 모둠의 치킨을 삽니다. (다른 반 구매는 켜고 끌 수 있음)
3. **종료**: 판매 결과를 확인합니다.
